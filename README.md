| [📄 rag-doc-qa](https://github.com/Cherie01234/rag-doc-qa) | PDFへの**Explainable RAG**（出典・根拠ハイライト、複数LLM切替） | LangChain, FAISS, OpenRouter | RAG設計・運用を想定したUI |
